# 📚 每日英语 - 初中英语学习网站

帮弟弟/妹妹自学英语的轻量级网站，**纯前端、免服务器、手机可用**。

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 📖 **卡片学习** | 翻转卡片，看英文背中文 |
| ✍️ **拼写练习** | 看中文拼英文，自动批改 |
| 🧠 **选择题** | 四选一，巩固记忆 |
| 📋 **每日任务** | 背诵→拼写→测验→复习，打勾完成 |
| 📈 **进度追踪** | 打卡日历、周统计、各年级进度 |
| 👨‍👩‍👧 **家长面板** | 爸妈查看学习天数、正确率、学习日志 |
| 🔥 **连续打卡** | 坚持天数一目了然 |

## 📖 词库

内置 **人教版初中英语词汇**，涵盖：

- 七年级上册（~130 词）
- 七年级下册（~100 词）
- 八年级上册（~80 词）
- 八年级下册（~100 词）
- 九年级全册（~150 词）

## 🚀 部署

### 方式一：GitHub Pages（推荐）

1. 把这个仓库 fork 或 push 到你的 GitHub
2. 去仓库 Settings → Pages → 选择 `main` 分支
3. 访问 `https://<你的用户名>.github.io/english-daily/`

### 方式二：本地直接打开

下载文件，双击 `index.html` 即可使用（数据存在浏览器 localStorage 里）

## 📱 使用说明

1. 左上角选择年级（根据孩子当前教材）
2. **学习页**：卡片浏览 → 拼写练习 → 选择题
3. **任务页**：每完成一个练习打勾，全完成点"今日任务全部完成"
4. **进度页**：看日历打卡记录、周统计、家长面板

## 🛠 技术栈

- 纯 HTML + CSS + JavaScript
- localStorage 存储数据
- 无任何外部依赖，无需服务器
- 移动端响应式设计
